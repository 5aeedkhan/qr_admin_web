# QR Admin Web Dashboard

A Flutter web application for managing users and generating QR codes/barcodes. This was developed as a **demo for a client** to showcase QR code generation, user management, and Firebase integration capabilities.

## 🚀 Features

- **User Management**: Create, view, update, and delete user records
- **QR & Barcode Generation**: Automatic generation of unique QR codes and barcodes for each user
- **Firebase Integration**: Real-time database with Firestore and authentication
- **Admin Authentication**: Secure login system with email/password
- **Responsive Design**: Modern UI optimized for web browsers
- **Subscription Tracking**: Monitor user payment status and remaining days

## 📋 Requirements

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Firebase project with Firestore and Authentication enabled
- Node.js (for Firebase CLI)

### Firebase Setup
1. Create a Firebase project
2. Enable Authentication (Email/Password)
3. Enable Firestore Database
4. Create an `admins` collection with admin email documents
5. Configure web app in Firebase Console

### Environment Setup
```bash
# Install Flutter
flutter --version

# Install Firebase CLI
npm install -g firebase-tools

# Login to Firebase
firebase login

# Configure Firebase for Flutter
flutterfire configure
```

### Dependencies
Key Flutter packages used:
- `firebase_core`: Firebase initialization
- `firebase_auth`: Authentication
- `cloud_firestore`: Database operations
- `flutter_riverpod`: State management
- `go_router`: Navigation
- `qr_flutter`: QR code display
- `uuid`: Unique ID generation
- `google_fonts`: Typography

## 🔧 Installation & Setup

1. **Clone the repository**
   ```bash
   git clone <repository-url>
   cd qr_admin_web
   ```

2. **Install dependencies**
   ```bash
   flutter pub get
   ```

3. **Firebase Configuration**
   ```bash
   flutterfire configure --project=your-firebase-project-id
   ```

4. **Run the application**
   ```bash
   flutter run -d chrome --dart-define=FLUTTER_WEB_USE_SKIA=false
   ```

## 📊 Database Schema

### Users Collection
```dart
{
  'id': String,
  'userName': String,
  'userId': String,
  'lastPayment': String,
  'status': String, // 'active' | 'inactive'
  'remainingDays': int,
  'lastDate': String,
  'qrCode': String, // Unique QR identifier
  'barcode': String, // Unique barcode identifier
  'createdAt': DateTime
}
```

### Admins Collection
```dart
{
  'email': String, // Admin email address
  'role': String,  // 'admin'
  'createdAt': DateTime
}
```

## 🎯 Usage

1. **Login**: Use admin credentials (email must be in `admins` collection)
2. **Dashboard**: View overview of all users
3. **Add User**: Create new users with automatic QR/barcode generation
4. **Manage Users**: Edit user details, view QR codes, track subscriptions
5. **Delete Users**: Remove users from the system
